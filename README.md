# NetFactory Lead Bot

Telegram-бот, который каждый будний день находит новые активные армянские бизнесы и присылает по каждому
готовую карточку: Instagram, справку о компании и персональное сообщение в Direct на армянском
от имени NetFactory. Отправляете вы сами, в один клик через кнопку «Открыть Direct».

## Как работает

1. **Поиск.** Google Maps через [Apify](https://apify.com) (Google Maps Scraper) по ~1 100 запросам вида
   «beauty salon in Arabkir, Yerevan»: ~60 категорий × районы Еревана и крупные города Армении. Ниши любые.
   Прогресс сохраняется: каждый день бот продолжает с того места, где остановился. Когда пройдёт всё,
   начнёт заново и подхватит компании, появившиеся на картах за это время.
2. **Instagram.** Берётся из карточки Google или со страницы сайта компании. Профиль проверяется
   напрямую в Instagram, бесплатно.
3. **Фильтр «новый и активный»:**
   - последний пост не старше 30 дней (`ACTIVE_DAYS`);
   - не больше 400 постов (`MAX_POSTS`) и не больше 200 отзывов в Google (`MAX_REVIEWS`): много постов
     и отзывов означает, что бизнес давно существует;
   - закрытые аккаунты отсеиваются. Количество подписчиков не учитывается.
4. **ИИ (Gemini)** читает данные из Google, описание сайта, био и последние посты. Решает, подходит
   ли компания, ставит оценку 1–10 и пишет сообщение: деловой тон, армянский, «Դուք», одна конкретная
   деталь об их бизнесе, одна идея автоматизации, предложение бесплатного 30-минутного звонка.
   В Telegram попадают лиды с оценкой от 6 (`MIN_SCORE`).
5. **Telegram.** Карточка с кнопками:
   - ✉️ **Открыть Direct** — сразу открывает переписку с компанией в Instagram;
   - текст сообщения: нажмите на него, чтобы скопировать;
   - ✅ **Отправил** / ❌ **Не подходит** — отмечает лид и пишет, кто именно отметил (удобно для команды);
   - 🔄 **Другой текст** — переписать сообщение.

Никому не пишем дважды: все проверенные компании и Instagram-аккаунты хранятся в `data/leads.sqlite3`.

## Бесплатный лимит Apify

Бот рассчитан на **бесплатный план Apify ($5 в месяц, без карты)**. Бесплатный план не может списать
деньги: когда кредиты кончаются, Apify просто останавливается до следующего месяца.

- Google Maps стоит примерно $5 за 1000 компаний. Бот берёт **35 компаний в будний день**
  (`APIFY_PLACES_PER_DAY`), это ~770 в месяц, примерно $4.
- Перед каждым поиском бот проверяет расход за месяц и останавливается на $4.5 (`APIFY_MONTHLY_BUDGET`).
- Из 35 компаний обычно проходят фильтр несколько: у многих нет Instagram, кто-то неактивен или
  давно на рынке. Ожидайте **примерно 2–6 лидов в день**. Точное число станет понятно после первой недели (`/stats`).
- Когда появится бюджет, просто увеличьте `APIFY_PLACES_PER_DAY` (на платном плане Apify)
  или вернуть поиск через Google Places API (он дешевле на больших объёмах).

## Установка (на своём компьютере)

### 1. Что нужно
- **Docker Desktop** — https://www.docker.com/products/docker-desktop/
- **Токен бота** — создать нового бота у [@BotFather](https://t.me/BotFather) (`/newbot`).
- **Ключ Gemini** — https://aistudio.google.com/apikey
- **Токен Apify** — зарегистрироваться на https://apify.com (бесплатно, без карты) →
  https://console.apify.com → *Settings → API & Integrations* → скопировать *Personal API token*.

### 2. Настройка
```bash
git clone https://github.com/Harut766/netfactory_bot-.git
cd netfactory_bot-
cp .env.example .env
```
Открыть `.env` и заполнить `BOT_TOKEN`, `APIFY_TOKEN`, `GEMINI_API_KEY` и `ALLOWED_USERS`
(Telegram ID через запятую, свой ID бот покажет на `/start`).

**Для команды:** создайте группу в Telegram, добавьте туда бота и коллег, напишите в группе `/id`
и впишите этот ID (начинается с `-100`) в `LEADS_CHAT_ID`. ID коллег добавьте в `ALLOWED_USERS`.
Лиды будут приходить в группу, и по кнопке «Отправил» все видят, кто кого уже взял.

### 3. Запуск
```bash
docker compose up -d --build
```
Логи: `docker compose logs -f`. Остановить: `docker compose down`.

Поиск запускается по будням в 10:00 по Еревану (`DAILY_TIME`, `DAILY_WEEKDAYS`), если компьютер включён
и Docker запущен. В любой момент можно запросить вручную.

## Команды бота
- `/leads` — найти лиды сейчас (`/leads 5` — пять штук, удобно для первого теста)
- `/stop` — остановить поиск
- `/stats` — сколько найдено и отправлено, почему отсеяны остальные и сколько потрачено в Apify
- `/id` — ID текущего чата

Поиск занимает 5–20 минут: бот проверяет Instagram в «человеческом» темпе, чтобы его не блокировали.
Если дневной лимит Apify уже потрачен, `/leads` ответит, что продолжит завтра.

## Если Instagram блокирует проверку
При частых запросах Instagram может временно перестать отдавать профили без логина. С домашнего IP это
бывает редко. Бот тогда предупредит и продолжит присылать лиды с пометкой «активность не проверена».
Блок обычно снимается через пару часов. Можно включить `APIFY_INSTAGRAM=true`: тогда профили будут
читаться через Apify, но это расходует тот же бесплатный бюджет.

## Настройка под себя
- Категории и города: `leadbot/queries.py`
- Описание NetFactory, идеальный клиент и правила сообщения: `SYSTEM_PROMPT` в `leadbot/llm.py`
- Фильтры и бюджет: `.env` (`ACTIVE_DAYS`, `MAX_POSTS`, `MAX_REVIEWS`, `MIN_SCORE`, `APIFY_PLACES_PER_DAY`)

После изменений: `docker compose up -d --build`.

## Важно
Бот сам **не отправляет** сообщения в Instagram: массовая автоматическая рассылка с аккаунта быстро
приводит к блокировке. Отправляйте вручную и не больше 20–30 новых диалогов в день с одного аккаунта.
