# NetFactory Lead Bot

Telegram-бот, который каждый будний день находит армянские бизнесы, изучает каждый и присылает
готовую карточку: Instagram, исследование компании и персональное сообщение в Direct на армянском
от имени NetFactory. Отправляете вы сами, в один клик через кнопку «Открыть Direct».

## Как работает

1. **Поиск.** Google Maps через [Apify](https://apify.com) (Google Maps Scraper) по ~1 100 запросам вида
   «beauty salon in Arabkir, Yerevan»: ~60 категорий × районы Еревана и крупные города Армении. Ниши любые.
   Прогресс сохраняется: каждый день бот продолжает с того места, где остановился. Когда пройдёт всё,
   начнёт заново и подхватит компании, появившиеся на картах за это время.
2. **Instagram.** Берётся из карточки Google или со страницы сайта компании. Профиль проверяется
   напрямую в Instagram, бесплатно.
3. **Исследование.** Бот читает сайт компании (текст, признаки онлайн-магазина, личного кабинета,
   онлайн-записи, мобильного приложения), профиль Instagram (био, последние посты) и данные Google Maps.
4. **ИИ (Gemini)** пишет короткое исследование компании, что у неё есть онлайн, оценку 1–10, идею
   автоматизации и сообщение: деловой тон, армянский, «Դուք», одна конкретная деталь об их бизнесе,
   предложение бесплатного 30-минутного звонка.
   **Карточку получает каждая купленная в Apify компания**, чтобы лимит не сгорал впустую:
   - нет Instagram — карточка с кнопкой WhatsApp (если есть телефон) и пометкой;
   - уже есть своё веб-приложение — карточка с пометкой ⚠️ и обычно низкой оценкой;
   - ИИ считает, что не подходит, — карточка с пометкой ⚠️, решаете вы.
   Не присылаются только дубли (тот же Instagram, например другой филиал сети).
   Если за запуск обработаны не все купленные компании (например, `/leads 3`), остальные ждут
   следующего запуска и не покупаются заново.
   Дополнительные фильтры (`ACTIVE_DAYS`, `MAX_POSTS`, `MAX_REVIEWS`, `MIN_SCORE`) по умолчанию выключены.
5. **Telegram.** Карточка с кнопками:
   - ✉️ **Открыть Direct** — сразу открывает переписку с компанией в Instagram;
   - 💬 **WhatsApp** — открывает чат по номеру из Google Maps;
   - текст сообщения: нажмите на него, чтобы скопировать;
   - ✅ **Отправил** / ❌ **Не подходит** — отмечает лид и пишет, кто именно отметил (удобно для команды);
   - 🔄 **Другой текст** — переписать сообщение.

Никому не пишем дважды: все проверенные компании и Instagram-аккаунты хранятся в `data/leads.sqlite3`.

## Бесплатный лимит Apify

Бот рассчитан на **бесплатный план Apify ($5 в месяц, без карты)**. Бесплатный план не может списать
деньги: когда кредиты кончаются, Apify просто останавливается до следующего месяца.

- Google Maps стоит примерно $5 за 1000 компаний. Бот берёт **40 компаний в будний день**
  (`APIFY_PLACES_PER_DAY`), это ~880 в месяц, примерно $4.4.
- Перед каждым поиском бот проверяет расход за месяц и останавливается на $4.5 (`APIFY_MONTHLY_BUDGET`).
- Каждая из 40 компаний превращается в карточку (кроме дублей), то есть **~40 карточек в будний день**.
- Когда появится бюджет, просто увеличьте `APIFY_PLACES_PER_DAY` (на платном плане Apify)
  или верните поиск через Google Places API (он дешевле на больших объёмах).

## Установка (на своём компьютере)

### 1. Что нужно
- **Docker Desktop** — https://www.docker.com/products/docker-desktop/
- **Токен бота** — создать нового бота у [@BotFather](https://t.me/BotFather) (`/newbot`).
- **Ключ Gemini** — https://aistudio.google.com/apikey
- **Токен Apify** — зарегистрироваться на https://apify.com (бесплатно, без карты) →
  https://console.apify.com → *Settings → API & Integrations* → скопировать *Personal API token*.

### 2. Настройка
```bash
git clone https://github.com/Harut766/netfactory_bot-.git
cd netfactory_bot-
cp .env.example .env
```
Открыть `.env` и заполнить `BOT_TOKEN`, `APIFY_TOKEN`, `GEMINI_API_KEY` и `ALLOWED_USERS`
(Telegram ID через запятую, свой ID бот покажет на `/start`).

**Для команды:** создайте группу в Telegram, добавьте туда бота и коллег, напишите в группе `/id`
и впишите этот ID (начинается с `-100`) в `LEADS_CHAT_ID`. ID коллег добавьте в `ALLOWED_USERS`.
Лиды будут приходить в группу, и по кнопке «Отправил» все видят, кто кого уже взял.

### 3. Запуск
```bash
docker compose up -d --build
```
Логи: `docker compose logs -f`. Остановить: `docker compose down`.

Поиск запускается по будням в 10:00 по Еревану (`DAILY_TIME`, `DAILY_WEEKDAYS`), если компьютер включён
и Docker запущен. В любой момент можно запросить вручную.

## Команды бота
- `/leads` — найти лиды сейчас (`/leads 5` — пять штук, удобно для первого теста)
- `/recover` — карточки по компаниям, уже оплаченным в Apify раньше, но оставшимся без карточки
  (Apify хранит результаты запусков около недели; новые компании не покупаются)
- `/stop` — остановить поиск
- `/stats` — сколько найдено и отправлено, почему отсеяны остальные и сколько потрачено в Apify
- `/id` — ID текущего чата

Поиск занимает 5–20 минут: бот проверяет Instagram в «человеческом» темпе, чтобы его не блокировали.
Если дневной лимит Apify уже потрачен, `/leads` ответит, что продолжит завтра.

## Instagram: Meta API (рекомендуется)
Без логина Instagram часто не отдаёт данные профиля. Тогда бот читает публичную страницу профиля,
а если закрыта и она, присылает лид с пометкой «активность не проверена». Надёжный способ —
**Instagram Graph API (Business Discovery)**: официальный, бесплатный, видит бизнес- и автор-аккаунты.
Личные аккаунты через него не видны, для них бот использует запасные способы.

Что нужно:
1. Ваш Instagram — профессиональный аккаунт (Business или Creator), привязанный к Facebook-странице.
2. Приложение на https://developers.facebook.com (тип *Business*) с продуктом **Instagram Graph API**
   (в новом интерфейсе — сценарий «Manage messaging & content on Instagram»).
3. Токен: *Tools → Graph API Explorer* → выбрать своё приложение → разрешения `instagram_basic`,
   `pages_show_list`, `pages_read_engagement`, `business_management` → *Generate Access Token*.
   Обычный токен живёт ~1 час: продлите его до 60 дней в *Tools → Access Token Debugger → Extend Access Token*
   (или создайте бессрочный токен системного пользователя в Meta Business Suite).
4. ID вашего Instagram-аккаунта: в Graph API Explorer выполните
   `me/accounts?fields=name,instagram_business_account` и возьмите `instagram_business_account.id`.
5. Впишите в `.env` `META_ACCESS_TOKEN` и `META_IG_USER_ID`, перезапустите бота.

Если токен истечёт, бот напишет «Meta API не отвечает» и продолжит работать запасными способами.

## Настройка под себя
- Категории и города: `leadbot/queries.py`
- Описание NetFactory, идеальный клиент и правила сообщения: `SYSTEM_PROMPT` в `leadbot/llm.py`
- Фильтры и бюджет: `.env` (`ACTIVE_DAYS`, `MAX_POSTS`, `MAX_REVIEWS`, `MIN_SCORE`, `APIFY_PLACES_PER_DAY`)

После изменений: `docker compose up -d --build`.

## Важно
Бот сам **не отправляет** сообщения в Instagram: массовая автоматическая рассылка с аккаунта быстро
приводит к блокировке. Отправляйте вручную и не больше 20–30 новых диалогов в день с одного аккаунта.
